# Contributing

Compass is intentionally blank. A contribution should reduce the temporary
reset surface or present evidence that one capability belongs globally across
unrelated projects.

Do not add project guidance, optional packs, source archives, templates, hosted
applications, generic utilities, or machine state. Git history already
preserves retired Compass implementation.

Before opening a pull request, run:

```powershell
git diff --check
.\reset\v1\test-all.ps1
```

Changes to `reset/v1/` must preserve preview-first behavior, exact fingerprint
ownership, unrelated live state, and focused round-trip coverage.
