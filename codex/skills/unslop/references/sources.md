# Sources

Read this provenance when auditing or revising Unslop, not during normal writing.

The September 2026 revision keeps its useful distinctions about empty claims,
plain language, and repetitive structure. It removes the instruction to add
personality and the fixed editing checklist after the user's portfolio review
showed how those can conflict with preserving a speaker's actual account.

The user described wording and cadence as part of the thought, and asked for
agent guidance that demonstrates the writing it requests. These are editorial
requirements from that review, not a claim that list formatting caused the
model's failures.

[Warp's account of improving its agents](https://claude.com/blog/how-warp-builds-self-improving-agents-on-claude)
(August 26, 2026; read September 5) supports explaining the reason behind an
instruction and making focused changes from observed feedback. It does not
establish that this particular revision improves model behavior.

[Oral History Association best practices](https://oralhistory.org/best-practices/)
(read September 5, 2026) informs preserving the narrator's perspective and
meaning when editing an account. Its interview and approval procedures are not
part of this general writing skill.
