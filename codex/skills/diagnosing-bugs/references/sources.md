# Sources

Read this provenance when auditing or revising Diagnosing Bugs, not during normal debugging.

The skill is substantially derived from Matt Pocock's `diagnosing-bugs` skill:

- Source: https://github.com/mattpocock/skills/blob/0ab1b63a410a03d3627979a109c8695de27af954/skills/engineering/diagnosing-bugs/SKILL.md

Compass keeps the upstream behavioral gates around a tight red-capable loop, minimization, falsifiable hypotheses, a correct regression-test seam, and rerunning the original symptom. It removes project-specific setup, the catalog of routine repro techniques, and interaction ceremony that current Codex does not need.
