# Ground In Sources

Find prior thinking strong enough to shape the artifact.

## Discover

- Name the decision, failure pattern, or philosophy the artifact needs.
- For changing behavior, confirm the exact current model or technology in its
  official catalog. Search releases, migrations, prompting guides, and
  changelogs from the last month. Reject superseded pages and resolve conflicts
  with the newest primary evidence.
- For durable ideas, search renowned practitioners and canonical books, papers,
  standards, talks, and interviews. Treat reputation as a lead, not proof;
  compare independent sources and let a stronger unknown source win.
- Use broad and secondary material to discover vocabulary and frameworks, then
  trace each useful idea to its original source.
- For example, "question requirements, delete, simplify" can uncover
  [Musk's engineering sequence](https://everydayastronaut.com/starbase-tour-and-interview-with-elon-musk/).
  An exact model name plus "prompting" or "migration" can uncover official
  [GPT-5.6](https://developers.openai.com/api/docs/guides/prompt-guidance-gpt-5p6)
  and [Claude Fable 5](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5)
  guidance.

## Extract And Distill

- Extract a principle, decision rule, sequence, boundary, or unusually clear
  wording that changes how the artifact will decide or act. Ignore citations
  that merely agree.
- Write the extracted philosophy for the artifact. Combine only distinct ideas,
  then prune without removing their decision power.
- Cite each contribution. Record model and date for changing guidance, label
  older model material as prior art, and name inference.
