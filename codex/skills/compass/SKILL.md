# Compass

Work in [ariobarin/compass](https://github.com/ariobarin/compass). Read its root
`AGENTS.md`, current manifest, and the files that own the request before deciding
what to change.

Turn the request into the smallest coherent Compass update. Let the repository
own placement, wiring, verification, and pull request practice. Do not cache its
rules here.

Use `$write-a-skill` when the request creates or revises a skill. For an
installation-only request, use the repository's current installer without
changing source.
